# Auditor de Tag VAST

Valida e analisa tags VAST XML (versões 2.0–4.2) com score de qualidade e checklist completo.

**URL:** https://falssp.github.io/Projeto-NC/ferramentas/auditor-vast/

## Funcionalidades
- Detecta versão VAST e tipo de Ad (InLine/Wrapper)
- Extrai e tabela todos os tracking events com status (obrigatório/recomendado/opcional)
- Lista todos os MediaFiles com tipo, delivery, dimensões e bitrate
- Score 0–100 baseado em verificações obrigatórias (60pts), recomendadas (30pts) e boas práticas (10pts)
- Destaque de sintaxe XML no painel de visualização
- Modo URL: instruções para obter o XML via DevTools
- Exporta relatório de auditoria em texto
