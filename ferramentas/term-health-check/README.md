# Term Health Check

Verifica a saúde e consistência de termos usados em nomenclaturas de campanha. Detecta termos obsoletos, variações não padronizadas, caracteres inválidos e frequência de uso por segmento.

## Como usar

- Importe ou cole a lista de nomenclaturas a verificar
- Execute o health check para análise completa dos termos
- Consulte o relatório de problemas encontrados por categoria
- Aplique as correções sugeridas e reexporte as NCs saneadas
