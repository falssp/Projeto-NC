# Gerador de Relatório Executivo

Formulário guiado que gera relatórios de performance de campanha formatados, com preview ao vivo.

**URL:** https://falssp.github.io/Projeto-NC/ferramentas/relatorio-executivo/

## Funcionalidades
- 4 steps: dados gerais, performance por canal, análise qualitativa, próximos passos
- Preview ao vivo do relatório enquanto preenche
- Resumo executivo gerado automaticamente com análise por canal
- Badges de performance (vs meta): verde ≥95%, amarelo 80–95%, vermelho <80%
- Donut CSS de budget entregue vs planejado
- Distribuição de budget por canal com barras visuais
- Próximos passos com responsável, prazo e prioridade
- Exporta: Imprimir/PDF, Copiar HTML, Copiar texto
- LocalStorage: salva rascunho automaticamente
