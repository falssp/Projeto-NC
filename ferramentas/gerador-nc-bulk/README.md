# Gerador NC Bulk

Gera nomenclaturas de campanha em lote a partir de combinações de segmentos. Permite definir múltiplos valores por posição e gerar automaticamente todas as combinações possíveis de NC, acelerando o processo de tráfego em campanhas com muitos itens de linha.

## Como usar

- Defina os segmentos base da nomenclatura (campanha, canal, formato)
- Adicione múltiplos valores por segmento para geração em bulk
- Visualize todas as combinações geradas automaticamente
- Copie ou exporte a lista de NCs para uso no tráfego
