# Dict Cross

Cruza dicionários de nomenclatura para verificar consistência entre diferentes fontes ou versões. Compara dois conjuntos de termos e identifica divergências, termos ausentes e mapeamentos conflitantes.

## Como usar

- Carregue ou cole o primeiro dicionário (referência)
- Carregue ou cole o segundo dicionário (a comparar)
- Visualize o resultado do cruzamento com divergências destacadas
- Exporte o relatório de diferenças encontradas
