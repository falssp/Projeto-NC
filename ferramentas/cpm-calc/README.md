# Calculadora CPM Equivalente

Calcula o CPM equivalente entre diferentes métricas de compra de mídia (CPC, CPA, CPV, CPL). Permite comparar eficiência de formatos e plataformas em uma base uniforme de custo por mil impressões. Útil para análise de mix de mídia e negociação com veículos.

## Como usar

- Selecione a métrica de entrada (CPC, CPA, CPV ou CPL)
- Informe o valor e as taxas de conversão/engajamento estimadas
- Veja o CPM equivalente calculado automaticamente
- Compare múltiplos cenários lado a lado
