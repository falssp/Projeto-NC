Comparador de Tag

O que faz

Coloca duas versões de uma tag lado a lado e mostra exatamente o que mudou — útil para revisar antes de atualizar uma tag em produção.

Como usar

  • Cole a tag original no campo A (antes) e a nova versão no campo B (depois).
  • A comparação acontece automaticamente após você parar de digitar.
  • Use ↕ Inverter A/B se colocou na ordem errada.

Como ler os resultados

  • Aba Parâmetros: tabela com valor A e valor B lado a lado. Fundo amarelo = mudou, verde = novo, vermelho = removido.
  • Aba Diff de texto: linha a linha — verde é o que foi adicionado, vermelho o que foi removido.
  • Aviso vermelho no topo: a URL base mudou — confirme se era intencional.

Limitação conhecida

O diff é linha a linha: se uma linha longa mudou só uma palavra, ela aparece inteira como removida e re-adicionada.

Documente os achados
