# Gerador NC — Combinatório de Nomenclaturas

Gerador combinatório de nomenclaturas de campanha. Cria todas as combinações possíveis de segmentos a partir de listas de valores por campo, seguindo a estrutura de NC Tool.

## Como usar

- Preencha os valores possíveis para cada segmento da NC
- O gerador cria automaticamente todas as combinações válidas
- Revise e filtre as NCs geradas conforme necessário
- Copie ou exporte a lista final de nomenclaturas
