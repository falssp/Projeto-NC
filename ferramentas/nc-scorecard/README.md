# NC Scorecard

Scorecard comparativo de múltiplas NCs — avalia e pontua com critérios customizáveis.

**URL:** https://falssp.github.io/Projeto-NC/ferramentas/nc-scorecard/

## Funcionalidades

- Cole uma lista de NCs para avaliação comparativa em lote
- Critérios de score configuráveis com pesos individuais
- Reset para critérios padrão
- Seletor de cliente/configuração
- Detecção automática de separador
- Tabela de resultados com score por NC e por critério
- Dados persistidos em localStorage
