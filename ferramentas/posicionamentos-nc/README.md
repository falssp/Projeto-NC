# Posicionamentos NC

Consulta interativa de posicionamentos (placements) conforme a Naming Convention do projeto — cruza posicionamento, dimensão e plataforma para garantir nomenclatura correta nos planos de mídia.

## Acesso

🔗 **[Abrir ferramenta](https://falssp.github.io/Projeto-NC/ferramentas/posicionamentos-nc/)**

## Descrição

Ferramenta de referência para validação de posicionamentos NC — permite consultar quais combinações de posicionamento, dimensão e plataforma são válidas na convenção do projeto, evitando erros de nomenclatura.

## Páginas

| Arquivo | Descrição |
|---------|-----------|
| `index.html` | Página principal — entrada da ferramenta |
| `posicionamentos.html` | Tabela completa de posicionamentos por plataforma |
| `dimensoes.html` | Dimensões por formato e posicionamento |
