# NC Glossary

Dicionário visual de termos NC organizado por segmentos.

**URL:** https://falssp.github.io/Projeto-NC/ferramentas/nc-glossary/

## Funcionalidades

- Sidebar com abas de segmento e contagem de termos por segmento
- Cadastro de termos com: valor, label, descrição, exemplo e tags
- Gestão de segmentos: adicionar, renomear e remover segmentos
- Guard contra duplicatas (mesmo segmento + mesmo valor)
- Busca em tempo real por valor, label ou tag
- Export JSON do glossário completo
- Dados persistidos em localStorage
