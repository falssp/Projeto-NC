# Analisador de Segmentos

Analisa a estrutura de segmentos de nomenclatura de campanha, identificando padrões, inconsistências e conformidade com o padrão NC. Avalia a qualidade dos segmentos por posição e gera um diagnóstico com sugestões de correção.

## Como usar

- Cole uma lista de NCs ou segmentos para análise
- Selecione o padrão de nomenclatura de referência
- Veja o diagnóstico por segmento com indicadores de conformidade
- Exporte o relatório de análise
