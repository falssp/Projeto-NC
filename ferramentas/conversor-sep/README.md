# Conversor de Separador

Converte separadores de nomenclaturas e planilhas entre diferentes padrões (ponto, vírgula, ponto-e-vírgula, pipe, underscore). Útil para adaptar exports de plataformas a formatos internos de nomenclatura.

## Como usar

- Cole o texto ou lista com o separador atual
- Selecione o separador de origem e o separador de destino
- Visualize o resultado convertido em tempo real
- Copie o output convertido com um clique
