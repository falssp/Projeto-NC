# Exportador NC — Documento de Nomenclatura

Gera documentos estruturados de nomenclatura de campanha a partir dos dados inseridos. Consolida NC, segmentos, plataformas e parâmetros em formato exportável para compartilhamento com equipes de tráfego e clientes. Suporta exportação em texto formatado.

## Como usar

- Preencha os campos de nomenclatura (campanha, canal, formato, período)
- Revise a NC gerada no preview estruturado
- Adicione observações e notas de tráfego
- Exporte o documento final em .txt para envio
