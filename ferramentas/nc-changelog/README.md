# NC Changelog

Registro de mudanças na Naming Convention com timeline e estatísticas.

**URL:** https://falssp.github.io/Projeto-NC/ferramentas/nc-changelog/

## Funcionalidades

- Timeline de entradas de changelog com data, tipo e descrição
- Tipos de entrada: adição, remoção, modificação, nota
- Filtros por tipo de entrada
- Estatísticas de evolução da NC ao longo do tempo
- Modal de criação de entrada
- Dados persistidos em localStorage

## Arquivos

```
ferramentas/nc-changelog/
```

## Stack

Vanilla JS + CSS — offline, sem dependências externas.
