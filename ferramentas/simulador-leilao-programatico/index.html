Como Funciona um Leilão RTB

  1. Usuário carrega a página — publisher envia bid request para SSP (AdX, Magnite…)
  2. SSP distribui a oportunidade para N DSPs em paralelo (latência máx. ~100ms)
  3. Cada DSP avalia o usuário e envia bid response com seu lance
  4. SSP ranqueia os lances válidos (acima do floor)
  5. Vencedor é escolhido e paga conforme o tipo de leilão (1st ou 2nd price)
  6. Ad server do publisher serve o criativo do vencedor
