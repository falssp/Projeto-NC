# ⏱️ Comparador de Janelas de Atribuição

**URL:** https://falssp.github.io/Projeto-NC/ferramentas/comparador-atribuicao/

Compare modelos e janelas de atribuição e veja o impacto nas conversões reportadas por canal.

## Funcionalidades

### Touchpoints
- Adicionar e editar pontos de contato na jornada do usuário
- Tipos: impressão, clique, conversão
- Data e hora individuais por touchpoint

### Configuração das janelas
- Janela de clique: 1, 7, 14, 28, 30, 60 ou 90 dias
- Janela de view-through: desativado, 1, 7, 14 ou 30 dias
- Modelo de atribuição: Last Click, First Click, Linear, Baseado em Posição, Decaimento Temporal

### Resultados
- Crédito de conversão por canal conforme janelas e modelo selecionados
- Tabela comparativa com todos os 5 modelos lado a lado
- Destaque automático do modelo selecionado
- Insights: canal com maior crédito, impacto do view-through, limitações do modelo

## Modelos suportados
| Modelo | Descrição |
|--------|-----------|
| Last Click | 100% do crédito para o último touchpoint |
| First Click | 100% do crédito para o primeiro touchpoint |
| Linear | Crédito igualmente distribuído entre todos |
| Posição (40/20/40) | 40% primeiro, 40% último, 20% distribuído |
| Decaimento Temporal | Mais crédito para touchpoints próximos à conversão |

## Dados e privacidade
- Sem backend — tudo processado no browser
- Funciona offline após carregamento
