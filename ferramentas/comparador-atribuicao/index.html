Guia de modelos

ModeloLógicaQuando usarLimitação
Last-Click100% para o último touchpointPerformance / lower funnel, quando o último clique é decisivoIgnora toda a jornada anterior
First-Click100% para o primeiro touchpointAwareness / prospecção, entender o que atrai novos usuáriosIgnora o que converteu
LinearDividido igualmente entre todosJornadas longas onde cada canal contribui de forma similarNão diferencia impacto real
Time-DecayMais peso para touchpoints próximos à conversãoCiclos de venda curtos; remarketing é decisivoSubestima a descoberta
Position-Based (U-shape)40% para o 1º, 40% para o último, 20% dividido nos demaisEquilíbrio entre awareness e conversãoArbitrário; ignora posições intermediárias
Data-DrivenPesos calculados por algoritmo (ML) baseado em dados históricosQuando há volume suficiente de dados (≥400 conv/mês)Caixa-preta; exige dados e plataforma compatível

⚖️ Como usar · Comparador de Atribuição

Visão geral

Use o Comparador de Atribuição para identificar diferenças e diagnosticar problemas entre fontes de dados.

Passo a passo

1
Cole os dados
Insira os dados de cada fonte nos campos correspondentes.
2
Execute a comparação
Clique em Comparar para analisar as diferenças.
3
Analise o resultado
As discrepâncias são destacadas com sugestões de causa e resolução.
4
Documente os achados
Exporte o diagnóstico para registro ou compartilhamento com o time.
💡 Dica: Todos os cálculos e gerações acontecem localmente no seu browser — nenhum dado é enviado para servidores externos.
