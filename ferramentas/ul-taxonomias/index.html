🏷️ Como usar · Dicionário de Taxonomias UL

Visão geral

Use o Dicionário de Taxonomias UL para criar e validar estruturas de nomenclatura padronizadas.

Passo a passo

1
Selecione o template
Escolha o tipo de campanha ou formato para aplicar a estrutura correta.
2
Preencha os campos
Complete cada componente da nomenclatura conforme solicitado.
3
Valide o nome
O sistema indica erros ou inconsistências na estrutura gerada.
4
Copie o resultado
Clique em Copiar para usar o nome gerado na plataforma.
💡 Dica: Todos os cálculos e gerações acontecem localmente no seu browser — nenhum dado é enviado para servidores externos.
