Construtor de Floodlight
Gere URLs de Floodlight Counter (contagem de eventos) e Floodlight Sales (receita) com todos os parâmetros.
Floodlight Counter — conta quantas vezes um evento ocorreu. O parâmetro ord= é gerado aleatoriamente para evitar cache (ord=[Random] no CM360, ou Math.random() via gtag). Use para pageviews, visitas, impressões de produto.
Floodlight Sales — registra receita associada a uma transação. O parâmetro ord= deve ser o ID único do pedido (não aleatório) para evitar contagem dupla. Use cost= para o valor da transação e qty= para quantidade.
Floodlight via VAST Tracking — para vídeo em CTV, streaming e ambientes sem JS. O ad server (CM360, VAST) inclui as URLs de tracking no XML e as chama automaticamente nos eventos de vídeo. Não requer JS na página.

Diferença Counter vs Sales

Counter: ord= aleatório a cada disparo → conta ocorrências. Ideal para pageview, visita, lead.

Sales: ord= = Order ID único → elimina duplicatas. Requer cost= para registrar receita. Ideal para compra, assinatura.

Quando usar cada tipo

Impression Tracker URL — pixel 1×1 disparado quando o anúncio carrega. Funciona em qualquer ambiente (CTV, app, DOOH) porque é apenas uma requisição HTTP — não precisa de JS.

Click Tracker URL — redirect que loga o clique antes de enviar o usuário ao destino. Coloque no campo de Click URL da plataforma. Não compatível com CTV (sem clique).

VAST Tracking URL — o player de vídeo chama a URL nos eventos de vídeo (start, quartis, complete). Obrigatório para vídeo em CTV, streaming e apps sem JS.

Tags de Verificação (IAS, DV, MOAT) — medem viewability, brand safety e tráfego inválido. Geralmente um JS tag para web; em CTV usam impression URL ou integração direta.
