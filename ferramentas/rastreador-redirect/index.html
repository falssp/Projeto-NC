Rastreador de Redirect de URL

Segue a cadeia de redirecionamentos de uma URL de clique hop a hop. Exibe status HTTP, servidor, tempo por hop e URL final. Detecta macros não substituídas e CORS.

Nota: alguns servidores bloqueiam chamadas de outros domínios (CORS). Nesses casos, a rastreador mostra até onde conseguiu seguir.

🔍 Como usar · Rastreador de Redirect

Visão geral

Use o Rastreador de Redirect para inspecionar e diagnosticar dados de tracking e tags.

Passo a passo

1
Cole a URL ou tag
Insira a URL, tag ou string que deseja inspecionar no campo de entrada.
2
Execute a análise
Clique em Analisar ou Inspecionar para processar os dados.
3
Revise os parâmetros
Os campos são exibidos de forma legível com seus respectivos valores.
4
Identifique problemas
Erros e alertas são destacados em vermelho ou amarelo.
💡 Dica: Todos os cálculos e gerações acontecem localmente no seu browser — nenhum dado é enviado para servidores externos.
