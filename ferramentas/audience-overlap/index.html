🔵 Calculadora de Audience Overlap

Segmentos de Audiência

Adicione audiências com seus tamanhos estimados e o percentual de overlap com cada uma das outras. O cálculo usa o princípio da inclusão-exclusão para estimar o alcance deduplicado.

Configuração de Overlap

Defina o percentual de overlap entre cada par de audiências. Exemplo: se A tem 100k e B tem 80k e 30% se sobrepõem, o overlap é de 30% do menor segmento.

Como Funciona
Inclusão-Exclusão: |A ∪ B| = |A| + |B| − |A ∩ B|
Para 3: |A ∪ B ∪ C| = |A| + |B| + |C| − |A∩B| − |A∩C| − |B∩C| + |A∩B∩C|

Overlap estimado (par): o % de overlap é aplicado sobre o menor dos dois segmentos. Para 3+ segmentos, a tripla interseção é estimada como o mínimo dos overlaps de pares dividido por 2.

Limitação: Overlaps reais entre audiências de diferentes plataformas (Meta, Google, DV360) não são diretamente mensuráveis sem um Data Clean Room. Este modelo é uma estimativa para planejamento.
