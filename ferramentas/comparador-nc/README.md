# Comparador de NC

Compara duas ou mais NCs de campanha lado a lado, destacando diferenças por segmento. Útil para detectar variações entre versões, identificar erros de digitação e validar consistência entre múltiplas nomenclaturas de um mesmo projeto.

## Como usar

- Cole as NCs que deseja comparar (uma por linha)
- Veja o diff visual segmento a segmento
- Identifique divergências destacadas em cor
- Exporte o relatório de comparação
