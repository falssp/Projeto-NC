# Detector de Discrepância

Compara métricas entre duas fontes (CM360 vs plataforma) e identifica discrepâncias com diagnóstico automático.

**URL:** https://falssp.github.io/Projeto-NC/ferramentas/detector-discrepancia/

## Funcionalidades
- Comparação manual (Fonte A vs Fonte B) ou multi-linha via paste de tabela
- Discrepância por métrica: Impressões, Cliques, Conversões, Receita
- Gauge visual com limiares IAB/MRC (Aceitável <10%, Atenção 10–20%, Alta >20%)
- Diagnóstico automático por padrão de discrepância
- Export: copiar relatório + baixar CSV
