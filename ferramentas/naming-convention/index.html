❓ Como usar — Naming Convention

O que é

Gerador de nomes padronizados para campanhas, adsets e criativos. Garante consistência no naming entre equipes e plataformas.

Como usar

1
Estrutura: a linha superior mostra os blocos do nome (ex: Cliente_Canal_Objetivo…). Você pode remover blocos clicando no × de cada um.
2
Adicionar blocos: clique nos chips abaixo da estrutura para adicionar categorias (Produto, Formato, Público etc.).
3
Separador: escolha entre underscore _, hífen -, pipe | ou ponto ..
4
Preencha os campos abaixo — o nome é gerado automaticamente em tempo real na barra de preview.
5
Batch: use a seção "Geração em Lote" para criar múltiplos nomes variando um único campo (ex: vários formatos).
6
Exportar: copie o nome pelo botão na barra de preview ou exporte a lista completa em CSV.

Exemplo prático

Campanha de awareness da Marca X no Meta:

Estrutura: Cliente _ Canal _ Objetivo _ Formato _ Data
Resultado: MARCAX_META_AWR_VIDEO15_202501
Tudo é convertido para MAIÚSCULAS automaticamente.

Dicas

💡
Evite espaços e caracteres especiais — use apenas letras, números e o separador escolhido.
💡
Combine o batch com formatos diferentes para gerar todos os nomes de uma campanha de uma vez.
