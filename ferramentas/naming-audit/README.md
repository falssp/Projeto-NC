# Naming Audit

Audita listas de nomenclaturas de campanha contra regras de convenção definidas. Identifica inconsistências, segmentos inválidos e desvios do padrão NC Tool com relatório detalhado por item.

## Como usar

- Importe ou cole a lista de nomenclaturas a auditar
- Configure as regras e padrões de validação
- Execute a auditoria para ver os erros por linha
- Exporte o relatório de auditoria com as ocorrências encontradas
