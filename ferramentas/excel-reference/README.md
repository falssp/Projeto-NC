# Excel Reference — NC Tool · Unilever BR

Guia interativo de referência para Excel/Google Sheets: funções, erros, exercícios práticos e assistente IA.

**Link:** https://falssp.github.io/Projeto-NC/ferramentas/excel-reference/  
**Repositório:** https://github.com/falssp/Projeto-NC/tree/main/ferramentas/excel-reference

---

## Abas

| Aba | Descrição |
|---|---|
| 📋 Referência | Catálogo de funções organizadas por categoria (Texto, Data, Lógica, Lookup, Matemática) com sintaxe, exemplos e casos de uso |
| 🚨 Erros | Guia de diagnóstico dos erros mais comuns (#REF!, #VALUE!, #N/A, #DIV/0!, etc.) com causas e soluções |
| 🎓 Treino | Exercícios práticos com feedback instantâneo para praticar as funções no contexto do NC Tool |
| 🤖 Assistente IA | Análise contextual via Gemini / Claude / GPT — tire dúvidas sobre funções e planilhas |

## Características

- 100% offline (exceto aba IA, que requer chaves de API)
- Dark mode / light mode automático
- Busca e filtro por categoria
- Chaves de API armazenadas no `localStorage` do browser (nunca transmitidas)

## Dependências

Nenhuma — HTML/CSS/JS vanilla, sem build.
