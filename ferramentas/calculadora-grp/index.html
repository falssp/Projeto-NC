Fórmulas base
GRP = Reach% × Freq. média — pontos brutos de audiência
TRP = Reach% (target) × Freq. média — focado no público-alvo
Reach% = GRP / Freq. média
Freq. média = GRP / Reach%
Com universo
Reach abs. = Universo × Reach%/100
Impressões = Universo × GRP/100
GRP = (Impressões / Universo) × 100
Benchmarks de mercado
• Campanha de alcance: 100–200 GRPs
• Lançamento / awareness: 200–400 GRPs
• Frequência recomendada: 3–5× para fixação
• Freq. ≥ 7+ pode causar saturação (wear-out)
Diferença GRP vs TRP
GRP usa a população total como denominador. TRP usa apenas o público-alvo (target). TRP é sempre ≥ GRP se o target for menor que o universo total.
