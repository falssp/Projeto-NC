Pixel Tester

Dispara qualquer URL de pixel — impression, click tracker, Floodlight, conversion — e mostra o resultado ao vivo: status, latência e se o pixel respondeu corretamente.

Pixels para testar
Pixels 1×1 são disparados via <img>. Outros via fetch no-cors. Status "opaque" = servidor respondeu (mesmo com CORS bloqueado).

🔍 Como usar · Pixel Tester

Visão geral

Use o Pixel Tester para inspecionar e diagnosticar dados de tracking e tags.

Passo a passo

1
Cole a URL ou tag
Insira a URL, tag ou string que deseja inspecionar no campo de entrada.
2
Execute a análise
Clique em Analisar ou Inspecionar para processar os dados.
3
Revise os parâmetros
Os campos são exibidos de forma legível com seus respectivos valores.
4
Identifique problemas
Erros e alertas são destacados em vermelho ou amarelo.
💡 Dica: Todos os cálculos e gerações acontecem localmente no seu browser — nenhum dado é enviado para servidores externos.
