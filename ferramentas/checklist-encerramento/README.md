# Checklist de Encerramento de Campanha

Checklist estruturado de pós-voo cobrindo todas as etapas para encerrar uma campanha de mídia digital com qualidade.

**URL:** https://falssp.github.io/Projeto-NC/ferramentas/checklist-encerramento/

## Seções

1. **Plataformas e Entrega** — pausar campanhas, confirmar datas, registrar desvios de entrega
2. **Tags e Pixels** — desativar Floodlights, gerenciar pixels de remarketing, documentar status
3. **Relatórios e Dados** — exportar relatórios de CM360, plataformas sociais, Path to Conversion
4. **Criativos** — arquivar assets, registrar performance, retornar materiais licenciados
5. **Financeiro e Faturamento** — confirmar budget realizado, make-goods, alinhamento com financeiro
6. **Análise e Pós-voo** — calcular KPIs realizados, registrar insights, preparar pós-voo
7. **Comunicação e Handoff** — enviar relatório ao cliente, atualizar sistemas, arquivar documentos

## Funcionalidades

- Prioridade por item: 🔴 Crítico / 🟡 Importante / ⚪ Recomendado
- Notas por item (texto livre)
- Suporte a até 5 campanhas simultâneas via localStorage
- Progress bar geral + contador por seção
- Exporta relatório de encerramento (texto) e PDF
