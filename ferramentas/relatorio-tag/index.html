Relatório de Tag

O que faz

Cria um relatório visual com todas as tags de uma campanha — status, tipo, plataforma — para compartilhar com o time ou o veículo.

Como usar

  • Preencha as informações da campanha no topo (anunciante, ad server, período etc.).
  • Adicione tags clicando em + Adicionar tag ou use Colar e detectar para colar uma tag real — o tipo é detectado automaticamente.
  • Preencha status, plataforma e ambiente para cada tag.
  • Clique em Gerar relatório para ver o resultado final.
  • Use Imprimir / Salvar PDF para exportar ou Copiar HTML para colar em um e-mail.

Status das tags

  • Pendente: ainda não enviada · Validada: revisada e aprovada · Problema: tem erro (fica em amarelo no relatório) · Enviada / Ao vivo: já em produção.

Atenção

Os dados não são salvos ao fechar ou recarregar a página. Gere o PDF antes de sair.
