Boas práticas
✅ Fazer❌ Evitar
Usar abreviações consistentes em todo o timeNomes longos com texto completo
Incluir o período para facilitar archivingEspaços e acentos (quebrando filtros)
Manter minúsculas + underscore como padrãoSiglas que mudam de campanha para campanha
Versionar criativos com v01, v02…Nomes genéricos como "campanha nova"
Incluir objetivo no nome para filtros de relatórioUsar datas no formato dd/mm/aaaa (gera erros)
