# Editor de Trafficking em Lote

Gerador de assets CM360 em 5 etapas — ad names, trafficking sheet, Floodlight tags e lista de placements.

**URL:** https://falssp.github.io/Projeto-NC/ferramentas/bulk-trafficking/

## Funcionalidades
- Step 1: Config base + preview de naming convention
- Step 2: Tabela de placements com CPM↔impressões↔budget auto-calc + import por paste
- Step 3: Criativos com badges de status
- Step 4: Configuração Floodlight + u-variables
- Step 5: Gera ad names, trafficking sheet, tag Floodlight, lista de placements — tudo copiável + CSV
- LocalStorage: salva rascunho automaticamente
