# 🎯 Planejador de Campanha Full-Funnel

Ferramenta estratégica para planejar campanhas distribuindo budget por etapa do funil e projetando KPIs com benchmarks de mercado BR.

🔗 **https://falssp.github.io/Projeto-NC/ferramentas/planejador-full-funnel/**

## O que faz

Wizard de 3 etapas:

1. **Configuração** — nome, objetivo, vertical, budget total, período, ticket médio, meta de ROAS
2. **Distribuição** — sliders interligados para Topo/Meio/Fundo (devem somar 100%), canal principal por etapa
3. **Projeção de KPIs** — estimativas de impressões, cliques, conversões, CPA, receita e ROAS com benchmarks de mercado

## Funcionalidades

- **Benchmarks por canal** — CPM, CTR e CVR de referência para YouTube, Meta, Google, DV360, LinkedIn, Programático
- **CVR ajustado por etapa** — conversão no fundo 10× maior que no topo (comportamento real de remarketing)
- **Cenários** — Conservador (×0,7) / Realista (×1,0) / Otimista (×1,3)
- **Funil visual CSS** — fluxo de impressões → cliques → conversões → receita
- **Validação de ROAS** — compara estimativa vs meta declarada com alerta colorido
- **Exportar plano** — texto formatado para colar em brief/proposta
