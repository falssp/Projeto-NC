# Calendário de Sazonalidade

Calendário visual de datas sazonais relevantes para o mercado brasileiro de mídia digital. Mapeia feriados, datas comemorativas, eventos de varejo e períodos de alta demanda para planejamento de campanhas.

## Como usar

- Navegue pelo calendário mensal para visualizar as datas sazonais
- Filtre por categoria (varejo, datas nacionais, eventos, etc.)
- Consulte o impacto estimado de cada período para mídia
- Use como referência no planejamento e briefing de campanhas
