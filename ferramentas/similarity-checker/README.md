# Similarity Checker

Detecta NCs semelhantes ou duplicadas em um conjunto de nomenclaturas de campanha. Calcula grau de similaridade entre strings, identificando variações sutis (typos, ordem de segmentos, caracteres especiais) que poderiam gerar duplicatas ou dados inconsistentes nos relatórios.

## Como usar

- Cole a lista de NCs para verificação de similaridade
- Defina o limiar de similaridade (ex: acima de 80%)
- Veja os pares de NCs identificados como similares ou duplicados
- Revise e corrija as inconsistências antes do tráfego
