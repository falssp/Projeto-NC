# Segment Coverage

Avalia a cobertura de segmentos em um conjunto de NCs, mostrando quais valores estão sendo usados em cada posição da nomenclatura. Identifica segmentos ausentes, subutilizados ou com alta concentração, auxiliando no planejamento de taxonomias.

## Como usar

- Cole o conjunto de NCs para análise de cobertura
- Veja a distribuição de valores por posição de segmento
- Identifique lacunas e concentrações na taxonomia
- Use os insights para otimizar a estrutura de NC
