Arquivos .xlsx, .xlsm e .xls. Planilhas do Google Sheets precisam ser baixadas como .xlsx primeiro (Arquivo → Baixar → Microsoft Excel).
Não. Todo o processamento ocorre inteiramente no seu navegador. Nenhum dado é enviado a servidores externos — o arquivo não sai da sua máquina.
Fórmulas "arrastadas" que mudam só o número da linha (ex: =VLOOKUP(C2,…), =VLOOKUP(C3,…)…) são reconhecidas como o mesmo padrão e exibidas uma única vez, evitando centenas de entradas idênticas. Desmarque a opção se suspeitar que alguma linha foi editada manualmente e quebrou o padrão.
Após extrair, use o botão Exportar na barra superior. Você pode baixar como HTML navegável (abre direto no browser, com busca) ou JSON estruturado (para integrar com outros sistemas).
Pode ser que a aba contenha só valores estáticos (fórmulas coladas como valor), esteja protegida no caso de arquivos .xlsm, ou as células usem formato de número em vez de fórmula.

Deduplicar fórmulas repetidas por linha

Quando uma fórmula se repete em várias linhas mudando só o número da linha (ex: a mesma fórmula "arrastada" da linha 2 até a linha 500), o extractor entende que é o mesmo padrão e mostra apenas um exemplo, em vez de listar as 499 repetições.

Exemplo:
D2: =VLOOKUP(C2,Tabela,2,0)
D3: =VLOOKUP(C3,Tabela,2,0)
... (497 linhas iguais)
→ Com a opção marcada: mostra só "D2: =VLOOKUP(C2,Tabela,2,0)"
→ Com a opção desmarcada: lista as 499 linhas

Quando desmarcar: se você suspeitar que alguma linha quebrou o padrão (foi editada manualmente, tem erro, ou fórmula diferente), desmarque para ver célula por célula.

Truncar fórmulas longas (>200 chars) na tela

Fórmulas muito compridas (com vários SE aninhados, concatenações longas, etc.) aparecem cortadas na tela para não quebrar o layout visual.

Importante: isso afeta apenas a exibição na tela. O arquivo exportado (HTML ou JSON) sempre traz a fórmula completa, sem corte.
