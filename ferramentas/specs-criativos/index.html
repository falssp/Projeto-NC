📖 Como usar · Specs de Criativos

Visão geral

Use o Specs de Criativos como referência rápida durante o planejamento e execução de campanhas.

Passo a passo

1
Busque o termo
Use o campo de busca ou os filtros de categoria para encontrar o que precisa.
2
Leia a definição
Cada entrada traz definição, contexto de uso e exemplos quando disponível.
3
Filtre por categoria
Use os filtros para focar em uma área específica (KPI, Vídeo, Programática…).
💡 Dica: Todos os cálculos e gerações acontecem localmente no seu browser — nenhum dado é enviado para servidores externos.
