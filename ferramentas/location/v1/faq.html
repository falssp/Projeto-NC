Tudo sobre a dimensão Location da taxonomia de campanhas Unilever BR — como funciona, como usar e como solicitar alterações.
🗺 O que é

Location é uma das dimensões da taxonomia de naming convention das campanhas Unilever BR. Ela indica a abrangência geográfica de uma campanha — de onde o público-alvo está.

Cada campanha recebe um valor de location que é usado no nome do placement, da linha de item e do criativo dentro do Ad Server (CM360).

A padronização garante que qualquer pessoa da equipe — ou do cliente — consiga entender de imediato a segmentação geográfica só de ler o nome do placement.

Também permite filtros, relatórios e análises automáticas sem depender de tratamento manual de dados.

O valor é inserido no campo Location da nomenclatura de campanha no NC Tool e aparece nos nomes de:

1
Campanha (Campaign)
2
Placement
3
Ad / Criativo

Nacional — quando a campanha não tem nenhum recorte geográfico. É o valor padrão para campanhas de awareness em mídia aberta ou digital sem segmentação.

Região — quando a compra de mídia é segmentada por macrorregião do Brasil (Norte, Nordeste, Centro-Oeste, Sudeste, Sul), mas não por estado específico.

Estado — quando a segmentação é feita por UF. Use quando a campanha roda em um ou mais estados determinados.

Cidade — quando a segmentação é hiperlocal, por município. Use quando a campanha tem targeting por CEP, raio ou cidade específica.

Regra geral: use o nível mais específico que o plano de mídia define. Se o plano diz "São Paulo e Rio de Janeiro", use cidades — não estados.

Não. Cada placement tem um único tipo de location. Se a campanha tem segmentações diferentes (um grupo nacional e um grupo por cidade), crie placements separados com os valores corretos para cada um.

Nunca combine tipos diferentes em um único valor. reg-se-cid-gru não é um valor válido.

Todos os valores são em letras minúsculas. A ferramenta já gera no formato correto — basta copiar.

Cidades com aeroporto comercial usam o código IATA do aeroporto (ex: gru para São Paulo/Guarulhos, rec para Recife).

Cidades sem aeroporto usam um slug do nome — o nome em minúsculas, sem acentos, com hífens no lugar de espaços (ex: sao-sebastiao para São Sebastião).

Na ferramenta, cidades com código IATA são marcadas com um ponto azul na lista.

Nacional não tem seleção — o valor nac é gerado automaticamente ao clicar no tipo.

Os filtros são apenas para facilitar a busca — a base tem 5.499 municípios. Ao selecionar uma região ou estado, a lista exibe só as cidades daquela área.

Os filtros não entram no valor gerado — apenas a seleção final de cidades importa.

A base atual cobre os 5.499 municípios do Brasil conforme o IBGE 2024. Se uma cidade não aparecer, pode ser que:

• O nome está diferente do oficial (ex: "São Paulo" vs "S. Paulo")
• A cidade precisa ser adicionada com uma sigla personalizada

Nesse caso, solicite a inclusão via Excel de referência — veja a seção Solicitar alterações.

🏙 Cidades e IATA

Cidades com aeroporto comercial têm um código IATA de 3 letras amplamente reconhecido (ex: gru, ssa, rec). Usar esse código deixa os valores mais curtos e universalmente compreensíveis.

São 143 cidades com código IATA na base atual.

São Paulo usa gru (Guarulhos), que é o aeroporto internacional principal. Campinas usa vcp (Viracopos) e São José dos Campos usa sjk.

Cada município é uma entrada separada — São Paulo, Campinas e São José dos Campos são cidades distintas na base.

Sim — o arquivo UL_Location_Taxonomy.xlsx tem uma aba dedicada "Cidades IATA" com as 143 cidades, seus códigos e estados.

O arquivo está disponível no repositório do projeto em ferramentas/location/.

🔗 Combinações

Selecione até 3 cidades na ferramenta — as siglas são concatenadas com hífen após o prefixo cid-:

SeleçãoValor gerado
São Paulocid-gru
São Paulo + Rio de Janeirocid-gru-rio
São Paulo + Rio + Belo Horizontecid-gru-rio-cnf

Estados combinados mantêm o prefixo est- em cada UF:

SeleçãoValor gerado
São Pauloest-sp
São Paulo + Rio de Janeiroest-sp-est-rj
SP + RJ + MGest-sp-est-rj-est-mg
SeleçãoValor gerado
Sudestereg-se
Sudeste + Nordestereg-se-ne
Sudeste + Sul + Nordestereg-se-su-ne

O limite de 3 vem da estrutura do naming convention — valores muito longos tornam o nome do placement ilegível e dificultam filtros no Ad Server.

Se a campanha precisa de mais de 3 localidades do mesmo nível, avalie subir um nível de granularidade (ex: usar estado em vez de múltiplas cidades do mesmo estado).
