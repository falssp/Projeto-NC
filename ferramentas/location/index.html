Sobre a ferramenta

Location indica a abrangência geográfica de uma campanha — de onde é o público-alvo. O valor gerado aqui é usado no naming convention dos placements, ads e criativos no CM360.

1
Selecione o Tipo na sidebar (Nacional, Região, Estado ou Cidade)
2
Para Cidade: filtre por região/estado e clique na cidade desejada. Para Estado ou Região: clique direto na lista
3
O valor aparece no campo Valor gerado — clique em Copiar e cole no NC Tool

Só para facilitar a busca — a base tem 5.499 municípios. Os filtros não entram no valor gerado: apenas as cidades selecionadas importam.

Tipos e valores

Nacional — campanha sem recorte geográfico, alcança todo o Brasil.

Região — compra segmentada por macrorregião (Norte, Nordeste, Centro-Oeste, Sudeste, Sul).

Estado — segmentação por UF. Use quando o plano define estados específicos.

Cidade — targeting hiperlocal por município. Use quando o plano define cidades específicas.

Regra geral: use o nível mais específico que o plano de mídia define.

Nunca combine tipos diferentes. reg-se-cid-gru não é um valor válido.

Valores muito longos tornam o nome do placement ilegível e dificultam filtros no Ad Server. Se precisar de mais de 3 localidades, suba um nível de granularidade (ex: use estado em vez de várias cidades do mesmo estado).

Cidades e IATA

Cidades com aeroporto comercial usam o código IATA (ex: gru para São Paulo, rec para Recife). São 143 cidades no total — marcadas com ponto azul na lista.

Cidades sem aeroporto usam um slug do nome: minúsculas, sem acentos, hífens no lugar de espaços (ex: sao-sebastiao).

A base cobre os 5.499 municípios do IBGE 2024. Se não aparecer, tente buscar pelo nome oficial completo. Se ainda assim não estiver, solicite a inclusão via Excel — veja a seção abaixo.
