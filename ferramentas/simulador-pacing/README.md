# 📈 Simulador de Pacing

Monitora o ritmo de entrega de campanhas e projeta o gasto até o fim do período.

**URL:** https://falssp.github.io/Projeto-NC/ferramentas/simulador-pacing/

## Funcionalidades

- Status: On Pace ✅ / Underpacing ⚠️ / Overpacing 🔴
- Barras visuais de período e budget com marcação do ponto esperado
- Daily budget recomendado para gastar no prazo
- Projeção de entrega ao ritmo atual
- Análise de impressões (opcional)
- Tabela de 3 cenários: manter ritmo, ajustar, acelerar máximo
- Histórico dos últimos 5 checks (localStorage)
- Datas auto-calculam dias decorridos e duração total
