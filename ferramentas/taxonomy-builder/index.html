⚙️ Como usar · Taxonomy Builder

Visão geral

Use o Taxonomy Builder para gerar estruturas padronizadas de forma rápida e consistente.

Passo a passo

1
Configure as opções
Preencha os campos e selecione as opções desejadas no painel de configuração.
2
Visualize a prévia
O resultado é gerado em tempo real conforme você preenche os campos.
3
Copie ou exporte
Clique em Copiar para área de transferência ou use o botão de exportação.
4
Valide o resultado
Verifique se a tag ou string gerada está correta antes de usar em produção.
💡 Dica: Todos os cálculos e gerações acontecem localmente no seu browser — nenhum dado é enviado para servidores externos.
