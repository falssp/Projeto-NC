# NC Preview

Visualizador de Naming Convention com chips coloridos por posição — suporta múltiplos clientes/configurações.

**URL:** https://falssp.github.io/Projeto-NC/ferramentas/nc-preview/

## Funcionalidades

- Cole uma NC e veja instantaneamente cada segmento como chip colorido
- Seletor de cliente/configuração com separador por cliente
- Histórico das últimas 30 NCs visualizadas
- Detecção automática de separador
- Suporte a múltiplos slots configuráveis
- Dados persistidos em localStorage
