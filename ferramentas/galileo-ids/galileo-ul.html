Como usar — Galileo IDs

Navegar

  • Use a barra lateral para filtrar por campo — clique para ativar ou desativar
  • Use a busca para encontrar um valor ou abreviação específica
  • Clique em qualquer card para ver a abreviação curta do Galileo
  • Use Expandir / Recolher para abrir ou fechar todos os cards de uma vez

Atalhos de teclado

  • / ou Ctrl+K — focar na busca
  • Esc — limpar busca ou fechar este modal

Estrutura dos campos

  • Campos GL — pertencem ao sistema Galileo (naming global UL)
  • Cada card mostra o valor completo e a abreviação usada no naming
  • Campos sem abreviação cadastrada aparecem como sem abreviação

Sobre

  • Dados extraídos da planilha oficial Grasp 2026 da Unilever BR.
  • Atualizado periodicamente conforme novas marcas, campanhas e segmentos são cadastrados.
