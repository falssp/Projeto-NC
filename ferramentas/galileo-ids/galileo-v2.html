Como usar — Galileo IDs

Navegar

  • Use a barra lateral para filtrar por parâmetro — clique em um ou mais para combinar
  • Use o menu Plataforma / Formato para filtrar por plataforma de mídia
  • Use a busca para encontrar qualquer campo, opção, sigla ou descrição
  • Clique em qualquer card para ver a descrição e a plataforma

Atalhos de teclado

  • / ou Ctrl+K — focar na busca
  • Esc — limpar busca / fechar modal
  • ↑ ↓ — navegar entre cards
  • Enter — expandir / recolher card

Expandir e recolher

  • Botão ⊞ Expandir — abre todos os cards visíveis
  • Botão ⊟ Recolher — fecha todos os cards
  • Respeitam os filtros ativos

Estrutura

  • Valores e abreviações usados no naming de campanhas Galileo
  • Ao expandir um card veja as plataformas onde o campo é usado
  • Clique num card para ver abreviação, descrição e plataformas
