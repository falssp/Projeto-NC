# Trafficking Sheet Generator

Gera planilhas de trafficking estruturadas para upload em ad servers (CM360, DV360). Organiza campanhas, placements, criativos e tags em formato padronizado pronto para importação.

## Como usar

- Preencha os dados da campanha (anunciante, placements, formatos)
- Configure as tags e criativos por placement
- Gere a trafficking sheet no formato do ad server desejado
- Exporte e use diretamente no upload do ad server
