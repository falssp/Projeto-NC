Métricas de Eficiência do Funil

CPL = Invest / Leads
CPA = Invest / Conversões Finais
CVR Total = Conv. Final / Entrada × 100
ROAS = Receita / Investimento

Lei de Pareto no Funil

Em geral, 80% das perdas de um funil estão concentradas em 1–2 etapas críticas (os "gargalos"). Identificar e otimizar o gargalo tem mais impacto do que melhorar todas as etapas uniformemente.

Tipos de Funil por Negócio

  • E-commerce: Imp → Clique → PDP → Carrinho → Checkout → Compra
  • Lead Gen B2B: Imp → Clique → LP → Lead → MQL → SQL → Cliente
  • App: Imp → Clique → Install → Registro → Ativação → Retenção
  • SaaS: Visita → Trial → Ativação → Upgrade → Churn
