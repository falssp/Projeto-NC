# Histórico NC — Snapshots de Nomenclatura

Registra e armazena snapshots do histórico de nomenclaturas de campanha ao longo do tempo. Permite comparar versões anteriores de NCs, rastrear mudanças e recuperar padrões passados com facilidade.

## Como usar

- Carregue ou cole as nomenclaturas atuais para criar um snapshot
- Navegue pelo histórico de versões salvas localmente
- Compare duas versões lado a lado para identificar diferenças
- Exporte o histórico em formato texto para documentação
