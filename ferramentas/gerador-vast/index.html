Gerador de VAST Tag

O que faz

Cria o XML de uma tag VAST para vídeo — o formato padrão que players de vídeo usam para carregar o anúncio e registrar eventos.

Como usar

  • Inline Ad: o próprio XML carrega o vídeo. Preencha título, duração e URL do arquivo de vídeo.
  • Wrapper: o XML aponta para outro VAST (encadeamento). Informe a URL do VAST de destino.
  • Marque os eventos de tracking que devem ser disparados (ex.: start, complete, impression).
  • Clique em Copiar XML ou Download XML para usar a tag.
  • Use ↺ Limpar campos para resetar o formulário.

Atenção

  • Os campos marcados com * são obrigatórios — ficam destacados em vermelho se vazios.
  • Se nenhum evento estiver marcado, o bloco de tracking fica vazio no XML — marque ao menos impression e start.
  • VAST 3.0 suporta mais eventos e é preferido para campanhas novas.
