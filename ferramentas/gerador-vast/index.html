Gerador de VAST Tag

O que faz

Cria o XML de uma tag VAST para vídeo — o formato padrão que players usam para carregar o anúncio e registrar eventos de tracking.

Como usar

  • Presets: carregue um modelo pré-configurado (Standard 30s, Skippable 5s, Wrapper, etc.) como ponto de partida.
  • Inline Ad: o próprio XML carrega o vídeo. Adicione um ou mais MediaFiles (formatos/bitrates diferentes).
  • Wrapper: encadeia outro VAST. Informe a URL do VAST de destino.
  • Pulável: marque "skippable" e defina o offset para gerar o atributo skipoffset no Linear.
  • Companion Ads: adicione banners exibidos junto ao player (StaticResource, IFrame ou HTML).
  • Pixels 3rd party: adicione pixels de terceiros por evento (DV360, Sizmek, viewability, etc.).
  • Error URL: URL disparada quando o player falha ao servir o anúncio — recomendada em produção.
  • Progress: marque o evento e defina o offset de disparo (ex: 00:00:15 = 15 segundos).
  • VAST 4.1: versão mais recente — adiciona namespace e UniversalAdId. Consulte o ad server para compatibilidade.

Ações de output

  • 📋 Copiar XML: copia o XML completo.
  • ⬇ Download XML: baixa como arquivo .xml.
  • 🔍 Validar (IAB): copia o XML e abre o validador da IAB Tech Lab — cole lá para validar.
  • ⇅ JSON: exporta ou importa todos os campos como JSON (para compartilhar com o time).
  • 💾 Salvar: salva no histórico local do browser (últimos 10).
  • 📋 Copiar todas: copia o bloco de URLs de tracking de uma vez (útil para QA).

Atenção

  • Campos com * são obrigatórios — ficam vermelhos se vazios.
  • VAST 3.0 é o padrão recomendado para campanhas novas. Use 2.0 para ad servers legados.
  • O histórico fica salvo apenas no browser local — não sincroniza entre dispositivos. Use o JSON para compartilhar.
