Gerador de VAST Tag

O que faz

Cria o XML de uma tag VAST para vídeo — o formato padrão que players usam para carregar o anúncio e registrar eventos de tracking.

Como usar

  • Presets: carregue um modelo pré-configurado como ponto de partida.
  • Inline Ad: o próprio XML carrega o vídeo. Adicione um ou mais MediaFiles.
  • Wrapper: encadeia outro VAST. Informe a URL do VAST de destino.
  • Pulável: marque "skippable" e defina o offset para gerar o atributo skipoffset.
  • Companion Ads: banners exibidos junto ao player (StaticResource, IFrame ou HTML).
  • Pixels 3rd party: pixels de terceiros por evento (DV360, Sizmek, viewability, etc.).
  • Verificação / Viewability: vendors OMID (IAS, Moat, DV) — gera <AdVerifications> em VAST 4.1 ou <Extension> em 2.0/3.0.
  • Timeline de eventos: visualiza em qual ponto do vídeo cada evento dispara.

CM360 VAST URL Builder

Gera a URL pfadx do CM360 para servir o criativo de vídeo diretamente. Preencha Network ID e Placement ID — a URL é gerada com os macros de click e cachebuster prontos para uso. Para testar como Wrapper, cole a URL gerada no campo "URL do VAST a envolver".

Checklist pré-tráfego

Roda automaticamente a cada alteração e aponta erros críticos (❌) e avisos (⚠️) antes de enviar a tag para o veículo. Um score de 100% indica que nenhum erro crítico foi encontrado.

Ações de output

  • 📋 Copiar XML: copia o XML completo.
  • ⬇ Download XML: baixa como arquivo .xml.
  • 🔍 Validar (IAB): copia e abre o validador da IAB Tech Lab.
  • ▶ Teste IMA: abre o Video Suite Inspector do Google.
  • 🔗 Compartilhar: gera link com a config codificada — quem abre já vê tudo preenchido.
  • ⇅ JSON: exporta ou importa todos os campos como JSON.
  • 💾 Salvar: salva no histórico local do browser (últimos 10).
  • 🎬 Preview do vídeo: reproduz o arquivo de vídeo do primeiro MediaFile.
  • 🖨 Imprimir tracking: imprime a lista de URLs de tracking em formato limpo.

Atalhos de teclado

  • Ctrl+Enter: regenera o XML (útil após editar campos manualmente).
  • Ctrl+Shift+C: copia o XML para a área de transferência.
  • Esc: fecha modais abertos.

Floodlight Counter Tag

Gera o pixel de contagem de conversão (<img>, URL ou iFrame) para colar na página de destino da campanha. Clique em "Copiar do VAST" para sincronizar os parâmetros src/type/cat automaticamente.

Verificação / Viewability

Use os presets IAS, Moat e DV para adicionar um vendor de viewability rapidamente — atualize o ID do script com seu token real. O botão "🔗 Check URLs" verifica se as URLs dos MediaFiles e pixels estão alcançáveis.

Atenção

  • Campos com * são obrigatórios — ficam vermelhos se vazios.
  • VAST 3.0 é o padrão recomendado para campanhas novas.
  • O histórico fica salvo apenas no browser local — use JSON ou link para compartilhar.
