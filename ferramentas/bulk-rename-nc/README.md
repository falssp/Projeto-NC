# Renomeador NC em Massa

Renomeia nomenclaturas de campanha em lote aplicando regras de padronização. Processa listas de NCs, corrige segmentos fora do padrão e gera o output renomeado de forma consistente.

## Como usar

- Cole ou importe a lista de nomenclaturas a renomear
- Configure as regras de substituição e padronização
- Visualize o preview das NCs renomeadas antes de confirmar
- Copie ou exporte o resultado final
