# QA Checklist Pré-Launch

Checklist de qualidade para validação de campanhas antes do go-live. Cobre verificação de NCs, tags de conversão, criativos, targeting, budget, datas e configurações de plataforma. Garante que todos os pontos críticos foram revisados antes da ativação.

## Como usar

- Selecione as plataformas da campanha em revisão
- Percorra os itens do checklist por categoria
- Marque os itens concluídos e registre observações
- Exporte o QA assinado para arquivo de campanha
