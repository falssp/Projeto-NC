🏷️ Como usar o Gerador de Tag Tracker

O que é

Gera tags de rastreamento (impression tracker, click tracker, VAST e script JS) prontas para colar no ad server ou na plataforma. Suporta CM360, Flashtalking, Adform, Sizmek e formato customizado.

Como usar

1
Selecione o ad server — CM360, Flashtalking, Adform, Sizmek ou Custom. Os campos de parâmetros mudam automaticamente.
2
Escolha o tipo de tag — Impression (pixel 1×1 para contar servings), Click Tracker (redireciona e conta cliques), VAST (vídeo, eventos start/quartis/complete) ou Script JS (tag assíncrona).
3
Preencha a URL base e os parâmetros do ad server (IDs de atividade, advertiser, placement etc.).
4
Ative as opções que precisar — cache-buster, HTTPS forçado, tag noscript.
5
Clique em Gerar Tags — as tags aparecem à direita. Use Copiar em cada bloco ou Exportar .txt para levar todas de uma vez.

Tipos de tag

🔵
Impression Tracker — pixel invisível 1×1 que dispara quando o anúncio é renderizado. Usado para contar impressões de 3rd party ou mensurar viewability.
🟢
Click Tracker — URL que redireciona o usuário para a landing page contando o clique no caminho. Necessário quando o ad server não é o primário.
🟡
VAST — XML completo com tracking de start, quartis (25%, 50%, 75%) e complete para vídeos in-stream. Também inclui impression e click.
🟣
Script JS — tag assíncrona <script> que carrega o pixel via JavaScript. Mais confiável em publishers modernos que bloqueiam pixels diretos.

Dica

Cache-buster: deixe sempre ativado. O [timestamp] ou [random] é substituído pelo ad server/plataforma na hora do serving e garante que cada impressão seja contada separadamente.
