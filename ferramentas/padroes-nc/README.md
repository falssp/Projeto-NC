# Padrões de NC

Repositório interativo de padrões de nomenclatura de campanha por plataforma e tipo de compra. Documenta as regras de cada segmento da NC, valores aceitos, limitações de caracteres e exemplos práticos por canal (CM360, Meta, Google, TikTok, LinkedIn).

## Como usar

- Navegue pelos padrões por plataforma ou tipo de campanha
- Consulte os valores aceitos por segmento de NC
- Use a busca para localizar regras específicas
- Copie exemplos prontos para validação
