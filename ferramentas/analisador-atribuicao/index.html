Fluxo da Jornada

Last Click

100% do crédito vai para o último canal antes da conversão. Simples mas ignora toda a jornada anterior. Favorece canais de fundo de funil (Search, Remarketing).

Crédito = 100% para último touch

First Click

100% do crédito para o primeiro canal de contato. Valoriza canais de descoberta/awareness. Ignora o papel dos canais de conversão.

Crédito = 100% para primeiro touch

Linear

Distribui o crédito igualmente entre todos os touchpoints. Mais democrático, mas não diferencia a importância relativa de cada canal.

Crédito = 100% / N para cada touch

Time Decay

Canais mais próximos da conversão recebem mais crédito. Usa função exponencial com meia-vida de 7 dias por padrão.

Crédito ∝ e^(−λ × dias_antes)

Position-Based (U-Shape)

40% para o primeiro, 40% para o último, 20% dividido entre os do meio. Equilibra descoberta e conversão.

First=40% | Last=40% | Middle=20%/N

Quando usar cada modelo

  • Last Click: campanhas de DR com objetivo de venda imediata
  • First Click: campanhas de awareness / branding
  • Linear: análise base, sem hipóteses fortes
  • Time Decay: ciclos de venda curtos (< 7 dias)
  • Position-Based: ciclos longos com múltiplos touchpoints
