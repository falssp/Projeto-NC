Video Ad Serving Template
VAST
XML estático · IAB · v2 → v4.2
Define como o ad server entrega um vídeo ao player. Descreve onde está o arquivo de vídeo, os pixels de tracking, cliques e durações. Padrão do mercado para CTV, OTT e programático.
Video Player Ad-serving Interface Definition
VPAID
JavaScript executável · IAB · v1 (SWF) → v2 (JS)
Código JS que roda dentro do player e assume controle total da experiência durante o anúncio. Permite interatividade avançada, mas em declínio acelerado por razões de segurança.

Quando usar cada um

Use VAST quando…

  • Campanhas em CTV, OTT, Smart TV
  • Inventário mobile in-app
  • Ambientes programáticos (DV360, TTD, Amazon DSP)
  • Objetivo é escala e reach
  • Publisher exige VAST (ex: Globo.com)
  • Segurança e compliance são prioridade
  • DoubleVerify / IAS rodando na campanha

Use VPAID quando…

  • Criativo exige interatividade avançada
  • Web desktop com publishers confiáveis
  • Viewability própria sem depender de terceiros
  • Publisher confirmou suporte ao VPAID 2.0
  • Nenhum substituto (SIMID) está disponível

Declínio do VPAID

⚠️ O VPAID está em declínio acelerado. Publishers e SSPs bloquearam ativamente o formato após incidentes de malvertising — código JS malicioso disfarçado de criativo publicitário.

Três fatores principais aceleram esse movimento:

01
Segurança — Publishers e SSPs bloquearam VPAID após incidentes de malvertising
02
CTV / OTT — Incompatível com o maior vetor de crescimento do vídeo digital
03
OMID — IAB criou o Open Measurement Interface Definition como substituto para viewability sem VPAID

Substitutos por necessidade

Viewability
OMID
IAS, MOAT e DV integrados via SDK — sem precisar de JS no player
Interatividade
SIMID
Secure Interactive Media Interface Definition — substituto seguro ao VPAID
Tracking avançado
VAST 4.2
Eventos adicionais e suporte nativo a OTT/CTV
Rich media em vídeo
HTML5 overlay
Camada separada do player — sem interferir no VPAID
