# Treinamentos | NC Tool — Unilever BR x Grasp

Materiais de treinamento organizados por tema e data.

## Estrutura

```
Treinamentos/
  RM_STORMX_ADP/
    23-07-26/
      v1/  <- versao original (HTML, PPTX, DOCX, manual)
      v2/  <- primeira atualizacao
      v3/  <- versao final de julho
    24-08-26/
         <- versao agosto (HTML completo, PPTX, DOCX, regras-taxonomia)
```

## Como adicionar novo treinamento

1. Cria pasta com nome do treinamento
2. Dentro, pasta com data (DD-MM-AA)
3. Sobe os arquivos: HTML, PPTX, DOCX
