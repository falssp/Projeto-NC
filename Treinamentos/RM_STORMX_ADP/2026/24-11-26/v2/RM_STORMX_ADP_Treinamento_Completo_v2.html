Preenchimento
Coluna Linha (G)
O que é

A coluna G (Linha) é o identificador da linha no plano de mídia. Ela conecta cada item da RM_STORMX ao respectivo item do Camphouse, garantindo rastreabilidade e integridade do dado.

Camphouse ID → Coluna G → RM_STORMX
Como preencher
  • Copiar o número de linha diretamente do Camphouse
  • Nunca reutilizar o mesmo número em linhas diferentes
  • Linhas novas recebem número sequencial após a última
  • Alterações na mesma linha mantêm o número original
  • Cancelamentos mantêm o número — apenas mudam o status

De onde vêm os dropdowns
Mandated Dimensions

Campos obrigatórios definidos globalmente pela Unilever. Não podem ser alterados pelo mídia — qualquer ajuste precisa de aprovação do Global.

Exemplos: Market, Brand, Campaign Name, Objective
Brand Pos Level

Nível de posicionamento da marca. Define como a campanha será categorizada no banco de dados para análise de performance.

Configurado pela StormX conforme briefing do cliente
Campaign By Brand Pos

Combinação de campanha por posicionamento de marca. Cruza os dados de campaign name com brand positioning para relatórios.

Atualizado no ADP toda segunda-feira
Todos os dropdowns da RM_STORMX são alimentados pelo ADP. Nunca digitar manualmente — apenas selecionar as opções disponíveis.

Qualidade
Validando a string
Passo 1
Verificar campos obrigatórios

Confirmar que todos os campos obrigatórios estão preenchidos: Campaign Name, Format Type, Creative Name, Position.

Passo 2
Checar caracteres especiais

Nenhum campo pode conter acentos, underscore, pipe, apóstrofo ou caracteres especiais (@, #, %, etc.).

Passo 3
Confirmar no NC Tool

Usar o NC Tool para gerar e validar o ID final. A string gerada é a que vai para a plataforma.

Uma string inválida gera erro no banco de dados. Validar antes de implementar na plataforma evita retrabalho e reprocessamento.
All rights reserved to Stormx @2026 // Digital Forward Stormx Aprove | Creative | Marketing
Atenção
Erros recorrentes
Ad Name duplicado

Mesmo Ad Name usado em dois Ad Groups diferentes. Cada Ad Name deve ser único e ter ID exclusivo.

Caractere especial na string

Acento, apóstrofo, travessão ou símbolos na taxonomia. Usar apenas letras sem acentuação, números e hífen.

Taxonomia de plataforma errada

Aplicar taxonomia do Meta em TikTok, ou vice-versa. Cada plataforma tem estrutura própria e incompatível.

Cópia de Ad Group sem nova taxonomia

Duplicar Ad Groups diretamente na plataforma sem solicitar nova taxonomia à StormX gera IDs incorretos.

Regras
Regras importantes
🚫 Proibido subir campanha sem taxonomia criada pela StormX. Em casos urgentes fora do expediente, comunicar por e-mail com autorização do cliente.
🚫 Nunca reduzir a taxonomia por conta própria para atender limites de caracteres da plataforma. Sempre informar a StormX.
🚫 Campaign Name genérico (como Always On Non Search) só é permitido enquanto o Campaign Name oficial ainda não foi aprovado.
📋 O Campaign Local deve ser sempre igual ao Campaign Name global. Informações extras vão no Campaign Local Extra — solicitado à StormX.
✅ Taxonomia genérica é aceita apenas em feriados/finais de semana com time de mídia sem informações. Corrigir em até 24h úteis.

Influenciadores
Classificação BRD / INF / UGC
BRD
Brand Say

Campanhas sem influenciador. Brand Handle apenas (Galileo). Não deve haver link de influenciador.

INF
Influencer

Campanhas com influenciador. Brand Handle + Influencer Handle (Galileo). Link obrigatório.

UGC
User Generated Content

Campanhas com influenciador usando Influencer Handle apenas (Galileo). Link obrigatório.

Atenção: quando Influencer Handle é usado, a quebra de Influencer Name some do freetext da taxonomia. A estrutura varia por plataforma — confirmar no ADP.

Prazos
Datas e alterações
⏰ Taxonomia genérica → correção em 24h

Quando a taxonomia genérica é usada por necessidade (feriado/final de semana), é obrigatório solicitar a correção em até 24 horas úteis após o início do expediente.

📅 Campaign Name oficial substitui o genérico

Assim que o Global enviar o Campaign Name oficial, todas as taxonomias devem ser ajustadas para refletir o novo nome — incluindo linhas já implementadas.

🔄 Twitter Amplify → correção retroativa

Linhas de Twitter Amplify com Publisher incorreto precisam ser corrigidas. Mudar de Twitter para Twitter-Amplify para o banco reconhecer corretamente.
