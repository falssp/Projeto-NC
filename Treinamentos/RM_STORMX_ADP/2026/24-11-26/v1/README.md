## O que mudou em relação a Ago/26

- **TikTok — Branded Mission e Buzz:** regra reforçada — só taxonomia TikTok, sem Compra Direta
- **TikTok Shop:** nova regra — só Campaign; Publisher=TikTok, Format=Product/Live, Position=TikTok-Shop-Skippable
- **TikTok Search:** novo — usar Position "TikTok-Search"
- **Twitter Amplify:** sem Ad Name; Publisher = "Twitter-Amplify"
- **YouTube Masthead CPH:** só taxonomia YouTube (implementada na plataforma); Buying Type: cph; Compra Direta não é mais necessária
- **Kwai EyeMax:** Position EyeMax → Creative Name = "eyemax"
- **Spotify Positions:** Feed-Display / Feed-Video / Carousel → Placement = "in-Feed"
- **Flashtalking:** cada veiculação separada = campanha diferente na Flashtalking
