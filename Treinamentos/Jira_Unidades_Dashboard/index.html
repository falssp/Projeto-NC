1. O problema

No Jira, a tarefa pai não tem valor de unidade e as tarefas filhas têm. O dashboard precisa mostrar no pai a soma dos filhos, mas sem contar em dobro no total.

O número do pai é só exibição. A unidade de verdade vive no filho.

2. A regra: 2 colunas

3. Implementação

BigQuery (view)

CREATE OR REPLACE VIEW `projeto.dataset.vw_jira_unidades` AS
WITH base AS (
  SELECT issue_key, parent_key, unidades
  FROM `projeto.dataset.tabela_jira`
),
soma_filhos AS (
  SELECT parent_key, SUM(unidades) AS unidades_filhos
  FROM base
  WHERE parent_key IS NOT NULL AND unidades IS NOT NULL
  GROUP BY parent_key
)
SELECT
  b.issue_key,
  b.parent_key,
  b.unidades,
  COALESCE(b.unidades, sf.unidades_filhos, 0) AS unidades_exibicao,
  b.unidades AS unidades_total
FROM base b
LEFT JOIN soma_filhos sf ON sf.parent_key = b.issue_key
A view cobre 2 níveis (pai → filho). Para 3+ níveis use a versão multi-nível logo abaixo (CTE recursiva); o Apps Script também é recursivo.

BigQuery — versão multi-nível (pai → filho → neto…)

Use quando a hierarquia tiver 3+ níveis. Premissa: a unidade é preenchida só nas issues de baixo; o pai exibe a soma de todos os descendentes.

CREATE OR REPLACE VIEW `projeto.dataset.vw_jira_unidades` AS
WITH RECURSIVE base AS (
  SELECT issue_key, parent_key, unidades
  FROM `projeto.dataset.tabela_jira`
),
arvore AS (
  SELECT issue_key AS raiz, issue_key AS descendente FROM base
  UNION ALL
  SELECT a.raiz, b.issue_key
  FROM arvore a
  JOIN base b ON b.parent_key = a.descendente
),
soma AS (
  SELECT a.raiz, SUM(d.unidades) AS unidades_desc
  FROM arvore a
  JOIN base d ON d.issue_key = a.descendente
  WHERE a.descendente <> a.raiz
  GROUP BY a.raiz
)
SELECT
  b.issue_key,
  b.parent_key,
  b.unidades,
  COALESCE(b.unidades, s.unidades_desc, 0) AS unidades_exibicao,
  b.unidades AS unidades_total
FROM base b
LEFT JOIN soma s ON s.raiz = b.issue_key

4. Configuração no Looker Studio

  • Fonte de dados = view do BQ (ou aba do Sheets) com as 2 colunas
  • Scorecards, totais e gráficos agregados → unidades_total (Soma)
  • Tabela de detalhe → issue_key + unidades_exibicao
  • Nunca misturar as duas métricas no mesmo scorecard

5. Checklist de validação

  • Total do dashboard = soma manual dos filhos + issues com valor próprio
  • Pai sem valor próprio mostra a soma dos filhos na tabela
  • Pai sem valor próprio não altera o total
  • Filtros (BU, marca, campanha, veículo) mantêm o total coerente
