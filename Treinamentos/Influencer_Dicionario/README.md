# Dicionário Influencer — Fórmulas e Cores por Rede

Guia de referência para a planilha `[UL] Dicionário_InfluencerName`: lógica de cada coluna automatizada (B, C, D, E, F) e regras de formatação condicional por plataforma na coluna D.

## Arquivos

| Arquivo | Descrição |
|---|---|
| `index.html` | Guia interativo completo (fórmulas + tabela de cores) |
| `influencer-dicionario.md` | Versão Markdown para consulta rápida |

## Visão rápida das colunas

| Col | Campo | Origem |
|---|---|---|
| A | Nome Do Influenciador ÚNICO | Manual |
| B | Nome_Do_Influenciador_ÚNICO | Fórmula ← A |
| C | SharePoint Name | Fórmula ← B |
| D | Rede Social | Fórmula ← H |
| E | Perfil na Rede Social (handle) | Fórmula ← H |
| F | Influencer Handle (alfanumérico) | Fórmula ← E |
| G | Qde de seguidores | Manual |
| H | Link | Manual |
