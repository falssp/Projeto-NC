Regra: Audience Type = Rmkt

Remarketing é construído sobre audiência que já teve contato direto com a marca, ou seja, dado de 1ª parte.

Audience PartyPermitido?Motivo
1pd-dadSimÉ 1PD
1pd-didSimÉ 1PD
1pd-diddadSimÉ 1PD (combinação)
no1pdNãoDeclara ausência de 1PD, o que contradiz remarketing
Qualquer 1pd-*. Nunca no1pd.

Quando a UL usar Rmkt com party errado

  1. Confirmar na taxonomia enviada qual gl_audience_party veio junto.
  2. Se for no1pd, devolver o ajuste: ou o type não é Rmkt, ou o party deve ser um 1pd-*.
  3. Se for 1pd-*, seguir normalmente.

Pendências

  1. Validar a regra de Rmkt com a Carolina.
  2. Confirmar o significado de dad / did / diddad com o dicionário global.
  3. Preencher as demais linhas da matriz.
