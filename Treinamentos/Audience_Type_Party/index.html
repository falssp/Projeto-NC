Audience Type × Audience Party

Quais gl_audience_party são permitidos para cada ft_audience_type

v3: matriz completa — padrão de mercado. Sujeita a ajuste caso a taxonomia UL defina regras específicas.

Resposta rápida: Audience Type = Rmkt

Permitido somente com 1PD-DID. Qualquer outro party (1PD-DAD, 1PD-DID+DAD, No 1PD) não é permitido.

O que significa cada Audience Party

PartySignificado
1PD-DIDSó dados próprios (1PD) de Digital ID Data: identificadores digitais anônimos coletados nas propriedades digitais da Unilever.
1PD-DADSó dados próprios (1PD) de Deterministic Audience Data: consumidores identificados por cadastro, CRM ou outras fontes determinísticas.

No 1PDNão usa dados próprios para segmentar a audiência.

Pontos de atenção

  • Matriz baseada em padrão de mercado. Se a taxonomia UL definir regras próprias que difiram daqui, este guia deve ser atualizado.
  • None como Audience Type indica entrega sem segmentação de audiência → padrão de mercado = No 1PD.
  • Abreviações de DID e DAD: confirme no dicionário da UL se as abreviações estão corretas — em versões anteriores havia inversão (1pd-did ↔ 1pd-dad).

Quando a UL usar um type com party fora da matriz

  1. Confirmar na taxonomia enviada qual gl_audience_party veio junto.
  2. Se a combinação não estiver na matriz (ex.: Rmkt + 1pd-dad), devolver o ajuste: ou o type muda, ou o party passa a ser um 1pd-* compatível.
  3. Se estiver na matriz, seguir normalmente.
