Taxonomia

Taxonomia

O que é
Sistema de nomenclatura padronizado de Campaign, Ad Group e Ad Name em todos os veículos digitais. Garante que qualquer pessoa entenda o que cada campanha representa.
Por que importa: Erros de taxonomia tiram dados do dashboard e do RROI. Janela de 30 dias para corrigir.
Estrutura — dois tipos obrigatórios
Campos Galileo Global
Padronizados pela UL Global. Separados por _. Não podem ser alterados sem autorização global.
Campos Freetext Brasil
Definidos localmente. Separados por |. Novos dropdowns alinham com UL Brasil antes de implementar.
Exemplo — Meta Campaign
cn010790-legacy-(hellmann's-world)_mayo_hellmann's_opauc_nocollab_awa_legacy|brdlft-y|promo|na
Ad Name
legacy-promo-4x5-meta-15s_vid_brand_nshop_15s_na_bsay_na_fed-stor-reel|brd|na|promo-15-SX00010803

IDs

IDs e relacionamento das linhas

Meta, TikTok e YouTube
1 linha = 1 ID único
Cada linha da RM tem um ID único que rastreia individualmente cada campanha / ad group / ad name.
Hierarquia de IDs
Campaign ID → Ad Group ID → Ad Name ID. O mesmo anúncio em campanhas ou Ad Groups diferentes recebe IDs vinculados ao seu Ad Group.
Pinterest, Twitter, DSP, Programático
1 ID único por Placement
A Flashtalking gera 1 ID único para cada Placement. Campaign e Ad Group IDs são do mesmo tipo sem hierarquia.
Atenção: a Stormx faz a mistura de informações de linhas diferentes ao gerar IDs, e isso pode causar erros de rastreamento. Sempre respeitar a hierarquia da RM.

Flashtalking

Flashtalking | Pontos importantes

Uma thread por campanha
Todas as peças de uma campanha seguem no mesmo e-mail. Nunca abrir nova thread para a mesma campanha.
Nada no a-sem tag no contador
Sempre manter o mesmo e-mail de saída. A equipe de Flashtalking entrega os contadores e a missão do time de compra é encaminhar para a agência.
Nova campanha na Double Verify
A nova campanha criada no lado cliente da Flashtalking verificar a DV. Com o Campaign ID da Flashtalking solicitar o Campaign ID da DV junto à Flashtalking (calculado automaticamente por eles).
Qual spec seguir
Seguir o Spec do Placement Type do FT, verificando os detalhes de tracking das peças. Para social: usar as specs próprias de cada rede social, sem tracking.
Sempre o mesmo e-mail
Manter sempre o mesmo e-mail de contato por campanha para centralizar todas as comunicações.
E-mail de contato UL: unilever.as@adsmovil.com

Validação de Dados

Validação de Dados | Diário, mensal e correções

Fluxo diário
O time de AdOps Stormx recebe alertas sobre novas taxonomias inseridas no banco de dados de análise. Se um ID é identificado no banco, o time de Engenharia de Dados é responsável pelo mesmo dia.
Fluxo mensal (RROI)
É fundamental cumprir os prazos para o relatório mensal. O RROI identifica e monitora a performance das campanhas constantemente no dashboard e no RROI.
Correção DV360/YouTube IO/AdName
IO com mais de 100 caracteres é deletado e recriado. Na plataforma, o erro é identificado na submissão de dados quando é encontrado no RROI. Correções nas campanhas deve ser feito por completo.
Caso haja erro, o time reporta no mesmo dia e o Engenheiro de Dados (ou quem for responsável) realiza a correção no mesmo dia. A correção deve ser sempre feita no RROI e verificada no dashboard.

Regras e Erros

Regras e Erros | Gerais

Taxonomia por plataforma
Nunca usar a taxonomia de uma plataforma em outra. Cada plataforma tem sua estrutura. A mistura compromete todos os componentes à frente.
Ad Name duplicado
Nunca usar o mesmo Ad Name duas vezes na mesma campanha (mesmo que sejam formatos diferentes). Se o Ad Name é duplicado no RROI, a taxa de erro sobe.
Cópia na plataforma
Duplicar Ad Group ou Ad Name cria cópia sem taxonomia. Se for necessário copiar, solicitar nova taxonomia antes, e só então copiar o anúncio.
Caracteres especiais
Alguns veículos não aceitam caracteres especiais. Sempre verificar antes de submeter a taxonomia. Exemplos: acentos, /, \, <, >, @, #, %, etc.
Taxonomia genérica
Criada em alguns casos para dar continuidade às campanhas enquanto a taxonomia correta é validada. Prazo de 24h úteis para correção.

Regras e Erros

Regras e Erros | Por plataforma

TikTok Shop
Não é possível alterar o Campaign Name, sem Ad Group com Ad Name. A campanha já existe e a Stormx cria as taxonomias. Primeiras linhas de taxonomia da RM.
Google PMax
Sem Ad Group não há Ad Name. Search: Publisher → google.search. Demand Gen: google-dmg.publisher → google-dmg.
Twitter Amplify
Planilha de Compra Direta com toda a hierarquia preenchida. A mídia preenche manualmente.
YouTube Masthead CPH
Colocar o Campaign Name com o Buying Type na taxonomy. O processo de entrega do Campaign Name ao cliente é mais rápido.
Flashtalking via API
Ad Group e Ad Name utilizados no Placement Name. Nomenclatura padrão deve seguir o ADP da Stormx.
Google Search / Demand Gen
Search: publisher = "google.search". Demand Gen: publisher = "google-dmg". Nunca misturar os publishers entre estas plataformas.
