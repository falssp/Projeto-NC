Boas práticas de trafficking

✓ Clicktag único por padrão — se houver múltiplos elementos clicáveis, usar Open Creative API (senão o clique principal é desativado)
✓ Borda de 1px aplicada em todo criativo (exigência de praticamente todo publisher + recomendação IAB)
✓ Declarar direção de expansão (Left/Right/Up/Down) coerente com o rail onde a peça vai rodar
✓ Se o criativo for MRAID, não declarar como expansível na Creatives Library — trava o spend

⚠️ Tamanhos de expansão máxima não foram extraídos do spec sheet da Flashtalking — confirmar no portal antes de usar como regra fixa, especialmente por veículo.

Quando usar cada formato

Display estático

  • Campanha de awareness/reach de alto volume
  • Inventário sem exigência de interatividade
  • Prioridade é peso leve e aprovação rápida

Rich Media / Expansível

  • Rail disponível (160x600, 300x250) com espaço de expansão
  • Objetivo exige mais espaço de mensagem sem sair do banner
  • Publisher confirma suporte a expansível

Vídeo

  • CTV, OTT, in-app, programático (DV360, TTD, Amazon DSP)
  • Precisa de medição de quartil/completion
  • Verificação de brand safety rodando (DoubleVerify / IAS)
Resumo

Specs base são IAB — mas quem manda é o publisher. Antes de subir qualquer peça fora do padrão listado aqui, confirmar o spec sheet do veículo no client portal da Flashtalking.
