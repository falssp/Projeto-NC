# Manual do Usuário — F5 FT Flashtalking Validator | NC Tool
> Versão 1.0

## Como acessar

1. Abra a planilha F5
2. No menu **NC Tool**, clique em **Abrir Validator**
3. O validador abre como dialog modeless

> ℹ️ O F5 não usa sidebar. Sempre abre como dialog modeless.

## Fontes de entrada

| Fonte | Como usar |
|---|---|
| ADP Excel | Carregue o arquivo ADP (.xlsx) — sistema lê a aba Flashtalking |
| Manual | Cole os ad names diretamente, um por linha |

## Resultados

| Status | Significado |
|---|---|
| ✅ Válido | Ad name correto |
| ❌ Inválido | Um ou mais erros |
| ⚠️ Exceção | Aprovado como exceção |

## Exceções

1. Clique no ícone ⚠️ na linha com erro
2. Preencha o motivo e confirme
3. A exceção fica registrada com data e responsável
