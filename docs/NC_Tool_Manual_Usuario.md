# Manual do Usuário — NC Tool | Unilever BR x Grasp
> Versão 2.0 · Cobre F1, F2, F3 e F4

## Visão Geral

| Fase | Nome | O que faz |
|------|------|-----------|
| F1 | IDs AdServer | Registra e controla IDs únicos por campanha/plataforma |
| F2 | Generator | Gera ad names seguindo a Naming Convention |
| F3 | Validator | Valida ad names contra o dicionário oficial |
| F4 | Acessórios | Ferramentas do dia a dia: Sync, Comparador, Merge RM→ADP |

## F1 — Como usar

1. Abra sua aba (com seu nome)
2. Na coluna **D**, cole ou digite o ad name
3. Na coluna **E**, selecione a plataforma
4. O sistema preenche automaticamente a data e os IDs

> ⚠️ Não edite as colunas A, B e C.

## F2 — Como usar

1. Abra a planilha F2
2. Clique em **Naming Tool** no menu
3. Selecione a aba da plataforma
4. Preencha os campos e clique em **Gerar**

## F3 — Como usar

1. Abra a planilha F3
2. Clique em **Abrir Validator** no menu
3. Escolha a fonte: ADP Excel, Dash, Manual ou Histórico
4. Selecione a plataforma e clique em **Validar**

## F4 — Como usar

Acesse pelo link do web app na Capa da planilha F4.
Módulos disponíveis: Gerador de IDs, ANS, Campaign Local, Dicionário de Influs,
Extrator de Influencer, Merge/Mapeador RM→ADP, Influencer Name Tool,
Extrator de Fórmulas, Comparador, Contador ADP, Removedor de Caracteres.
